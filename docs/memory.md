# 个性与记忆

DeepSeek 的 chat API 无状态，没有官方的个性与记忆能力。deepseek-lite 在客户端实现等价物，数据全部存本机 SQLite。

## 自定义指令（个性）

设置 → 个性与记忆，开关加两栏输入：

- **关于我**：身份、背景、约束（"我是后端工程师，在上海"）
- **回复风格**：希望模型如何回应（"简洁直接，先给结论"）

两栏内容拼进每次对话的 system prompt，等价于 ChatGPT 的 Custom Instructions 或 Gemini Gems 的指令栏。

## 记忆

记忆是"关于用户的长期事实"列表，注入每次对话（上限 30 条，单条 120 字）。三种模式：

| 模式 | 行为 |
| --- | --- |
| 仅手动 | 自己添加、编辑、导入，全部注入对话 |
| 自动提取 | 在仅手动的基础上，每轮对话完成后后台调一次 `deepseek-flash`（关闭思考）提取 0-3 条值得记住的用户事实，归一化去重后入库，聊天页弹出「💡 已记住」提示 |
| 关闭 | 不注入也不提取 |

记忆来源有三种标记：手动 / 自动 / 导入，每条可停用（不注入）、编辑、删除。

### 导入记忆

- 粘贴 Gemini「保存的信息」页面文本（[gemini.google.com/saved-info](https://gemini.google.com/saved-info)，该页面只能复制不能导出文件）
- ChatGPT 导出包中若包含 memories 类 JSON，可文件导入
- 任意"每行一条"的纯文本

### 对话级开关

聊天页输入栏的「记忆」胶囊控制单个对话：

- 点亮（默认）：本对话注入全局记忆，自动模式下也从本对话提取
- 熄灭：本对话不注入、不提取，**摘要也不会进入其他对话的参考**——适合不想留痕的单独对话

全局记忆模式为「关闭」时不显示该胶囊。

## 跨对话参考

设置中的开关。开启后，近期 5 个对话的摘要会注入当前对话的 system prompt（"用户近期其他对话的摘要，供了解背景，避免重复询问已知信息"），等价于 ChatGPT 的「参考聊天记录」。对话级记忆关闭的会话不参与。

## 会话摘要

每个对话自动维护一份约 120 字的内容摘要：概括话题、人物/世界观设定（含角色扮演）、当前进展。

- 6 条消息后首次生成，之后每新增 8 条滚动更新，由后台轻量调用完成，无手动入口
- 会话列表每行标题下直接展示
- 随导出的 Markdown 一并输出

摘要同时是跨对话参考的数据来源。
